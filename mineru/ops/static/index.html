推荐测试顺序

  1. 基线micro-batch 1，重试 0，记录完整快照。
  2. 提高吞吐依次测试 2、4、8，并与同数据集基线比较。
  3. 观察拐点关注 P95、慢页、超时页和失败页，而不只看平均速度。
  4. 复盘现场导出 Markdown/CSV，报告中保留数据集和配置哈希。
  5. 压力档位16 / 32 仅用于压力测试，可能增加显存占用、耗时和失败概率。
