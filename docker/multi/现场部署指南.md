# 多实例现场部署

本目录的 Compose 服务是三个 API 和一个 Router，三个 VLM 服务需要独立部署，并在 `env.multi` 中配置地址。

## 准备

在 API/Router 主机导入两个归档：

```bash
cd docker/base
./build.sh import /path/to/export
```

归档文件为：

```text
mineru-env-v1.0.tar.gz
mineru-code-v3.4.2.tar.gz
```

在 VLM 主机另外导入与硬件匹配的 `mineru-server` 镜像，并准备模型目录。模型目录通过 `VLM_MODEL_HOST_PATH` 挂载，离线环境不会自动下载。

## 启动

```bash
cd docker/multi
cp env.multi.example env.multi
vim env.multi
./start-multi.sh start
```

Router 地址默认为 `http://<host>:8002`，API 地址默认为 `18000`、`18001`、`18002`。启动前应确认每个 `VLM_n_IP:VLM_n_PORT` 已经可以从对应 API 主机访问。

## 更新代码

有网机器导出新 `mineru-code-<tag>.tar.gz`，在每台 API/Router/VLM 主机导入后，将 `env.multi` 中的 `MINERU_CODE_IMAGE` 改为新标签并重新执行：

```bash
./start-multi.sh stop
./start-multi.sh start
```
