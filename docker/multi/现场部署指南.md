# MinerU API + Router 现场部署指南

## 你手上的文件

```
mineru-full-v1.0.tar.gz    # Docker 镜像（约 6GB）
compose-multi.yaml          # Docker Compose 配置
env.multi.example           # 配置模板
```

## 部署步骤

### 第一步：加载 Docker 镜像

```bash
gunzip -c mineru-full-v1.0.tar.gz | docker load
```

看到 `Loaded image: mineru-full:v1.0` 说明成功。

### 第二步：创建配置文件

```bash
cp env.multi.example env.multi
```

### 第三步：编辑配置文件

```bash
vim env.multi
```

**只改这两行**（改成你实际的 VLM Server 地址）：

```bash
VLM_1_IP=你的VLM服务器IP
VLM_1_PORT=你的VLM服务器端口
```

其他保持默认不动。

### 第四步：启动服务

```bash
docker compose -f compose-multi.yaml --env-file env.multi up -d
```

### 第五步：验证

```bash
# 查看服务状态（应该看到 mineru-api 和 mineru-router 都是 running）
docker compose -f compose-multi.yaml --env-file env.multi ps

# 测试 API 是否正常（应该返回 {"status":"healthy"...}）
curl -s http://localhost:18000/health

# 测试 Router 是否正常（应该返回 {"status":"healthy"...}）
curl -s http://localhost:8002/health
```

## 停止服务

```bash
docker compose -f compose-multi.yaml --env-file env.multi down
```

## 查看日志

```bash
# 查看 API 日志
docker logs -f mineru-api

# 查看 Router 日志
docker logs -f mineru-router
```

## 常见问题

### Q: 启动报错 "No healthy upstream"？

A: 等 30 秒再试。API 启动需要时间，Router 会等 API 健康后再启动。

### Q: curl 测试不通？

A: 检查 VLM 地址是否正确：`vim env.multi`，确认 `VLM_1_IP` 和 `VLM_1_PORT`。

### Q: 想重新启动？

```bash
docker compose -f compose-multi.yaml --env-file env.multi down
docker compose -f compose-multi.yaml --env-file env.multi up -d
```
